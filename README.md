## 🚀 Quick Start

### Option 1: Open Directly
```bash

```

### Option 2: Local Server (Recommended)
```bash

# Using Node.js
npx serve

php -S localhost:8000
```

Then visit: `http://localhost:8000`

## 📝 Customizing Project Pages

All project pages are in the `projects/` folder. To customize:

1. **Open a project file** (e.g., `projects/album-cover.html`)
2. **Update these sections:**
   - Title & meta description (in `<head>`)
   - Project hero (title, intro, tags)
   - Featured image path
   - Project overview (role, timeline, tools)
   - The Challenge section
   - Design Process (4 steps)
   - Key Features (4 cards)
   - Results & Impact
   - What I Learned
   - Next project link

3. **Save and test**
