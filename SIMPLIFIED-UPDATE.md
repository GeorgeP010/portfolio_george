   ```bash

   ```

2. **Pas alleen deze delen aan:**
   - Line ~8: `<title>` tag
   - Line ~32: Project title
   - Line ~35-38: Intro tekst
   - Line ~52: Image path (als je andere image hebt)
   - Line ~61: Year
   - Line ~66-67: Role
   - Line ~72-73: Services
